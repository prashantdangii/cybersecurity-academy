    03concept · terminal · lab

    Read files

    Concept

    Don't open an editor just to peek. Prefer head/tail for ends, less for paging, cat for short files.

    Risky habit

    • cat huge logs into the terminal
    • Ignore binary files (garbage / hang)

    Better

    • head -n 50 file · tail -f for live
    • less file · /search · q to quit
    • file path — what type is this?

    Mission terminal

    MissionRead notes.txtcd lab if needed, then cat / head notes.txt
    bash · readlive
    lab@shell:~/lab$

    • Full file (cat notes.txt)
    • First lines (head notes.txt or head -n 5 notes.txt)
    cat notes.txt
head -n 20 /var/log/syslog
tail -n 50 /var/log/auth.log
less /etc/passwd   # q to quit
file /bin/ls

    Create & move files

    Concept

    Build structure on purpose. rm is permanent here — no Trash. Prefer rm -i while learning.

    mkdirmake directory
    touchempty file / timestamp
    cp / mvcopy or rename/move
    rmdelete — careful
    Danger

    Never run rm -rf / or wild deletes as root. Scope paths. Use rm -ri dir when unsure.

    Permissions

    Concept

    ls -l shows mode: type + user/group/other each with rwx. Attackers hunt world-writable and SUID bits.

    rread · 4
    wwrite · 2
    xexecute · 1
    ModeMeaningOctal
    -rwxr-xr-xowner rwx · group/other rx755
    -rw-r--r--typical file644
    drwx------private directory700

    Mission terminal

    MissionHarden a scriptls -l tool.sh, then chmod 755 tool.sh
    bash · permslive
    lab@shell:~/lab$

    • Inspect (ls -l tool.sh)
    • Make executable (chmod 755 tool.sh or chmod +x tool.sh)
    ls -l tool.sh
chmod 644 notes.txt
chmod 755 tool.sh
chmod +x tool.sh
# see who owns it

    06concept · terminal · lab

    Find anything

    Concept

    Recon on disk: find by name/type/perm, which for binaries on PATH, grep -R for content.

    • find . -name '*.conf'
    • find / -perm -4000 — SUID (careful)
    • which nmap
    • type cd — builtin vs binary
    • grep -Rni 'password' .

    Mission terminal

    MissionLocate secrets.txtfind . -name secrets.txt
    bash · findlive
    lab@shell:~/lab$

    • Find the file (find . -name secrets.txt)
    • Locate a binary (which bash)
    find . -name '*.txt'
find . -type f -size +1M
which python3
grep -Rni 'api_key' . --include='*.env'

    Pipes & filters

    Concept

    Unix power move: one tool's stdout → next tool's stdin with |. Redirect with > (overwrite) and >> (append).

    ps auxlist processes
    grep sshfilter lines
    wc -lcount
    > out.txtsave

    Mission terminal

    MissionFilter auth noisecat auth.log | grep Failed · then wc -l
    bash · pipeslive
    lab@shell:~/lab$

    • Filter Failed (cat auth.log | grep Failed or grep Failed auth.log)
    • Count hits (cat auth.log | grep Failed | wc -l or grep -c Failed auth.log)
    cat auth.log | grep Failed
grep Failed auth.log | wc -l
ps aux | grep nginx
sort users.txt | uniq -c | sort -nr
echo hi >> out.txt

    08concept · terminal · lab

    Processes

    Concept

    Every running program has a PID. List with ps, inspect with top/htop, stop with kill — know the signal.

    pssnapshot
    toplive view
    killSIGTERM default
    • ps aux — all users
    • kill PID — polite stop
    • kill -9 PID — force (last resort)
    • jobs / fg / bg — shell jobs
    • Ctrl+C — SIGINT foreground
    • Ctrl+Z — suspend

    Mission terminal

    MissionFind the noisy processps aux | grep miner · note the PID
    bash · processeslive
    lab@shell:~/lab$

    • List processes (ps aux)
    • Find miner (ps aux | grep miner)
    ps aux | head
ps aux | grep nginx
kill 1234
kill -9 1234   # only if needed
top            # q to quit
