    SQL injection

    Concept

    String-built SQL lets attackers change the query structure. Fix: PreparedStatement / JPA parameters — never concatenate.

    Vulnerable

    String q = "SELECT * FROM users WHERE name='"
  + name + "'";
stmt.executeQuery(q);

    Fixed

    PreparedStatement ps = conn.prepareStatement(
  "SELECT * FROM users WHERE name=?");
ps.setString(1, name);
ps.executeQuery();

    XSS in Java web

    Concept

    Untrusted data reflected into HTML/JS becomes the attacker’s script. Fix at the sink: context-aware encoding (or safe templates).

    Vulnerable

    out.println("<p>Hi " + name + "</p>");

    Fixed

    // OWASP Java Encoder / templating auto-escape
out.println("<p>Hi " + Encode.forHtml(name) + "</p>");
    • Reflected — in the response now
    • Stored — saved then shown
    • DOM — browser-side sink
    • CSP — defense in depth

    04concept · code · terminal · check

    Path traversal

    Concept

    ../../etc/passwd rides along when you build filesystem paths from input. Resolve + verify the path stays under a base directory.

    Vulnerable

    Path p = Paths.get("/data/uploads/" + file);
Files.readAllBytes(p);

    Fixed

    Path base = Paths.get("/data/uploads").normalize();
Path p = base.resolve(file).normalize();
if (!p.startsWith(base)) throw new SecurityException();
Files.readAllBytes(p);

    Access control in code

    Concept

    Hiding a button is not authz. Every controller/service method must enforce who can touch which object.

    Vulnerable

    @GetMapping("/invoices/{id}")
Invoice get(@PathVariable long id) {
  return repo.findById(id).orElseThrow();
}

    Fixed

    Invoice inv = repo.findById(id).orElseThrow();
if (!inv.getOwnerId().equals(currentUserId()))
  throw new AccessDeniedException();
return inv;
    • IDOR — change id, get others’ data
    • @PreAuthorize — Spring method security
    • Deny by default

    Use vetted libraries and modern defaults. Password storage ≠ reversible encryption.

    08concept · code · check

    Deserialization

    Concept

    Java serialization can turn bytes into objects — and gadgets into RCE. Don’t deserialize untrusted data with native serialization.

    Dangerous

    ObjectInputStream ois =
  new ObjectInputStream(userBytes);
Object o = ois.readObject();

    Safer

    • Prefer JSON with strict POJOs (Jackson after hardening)
    • Avoid native Java serialization across trust boundaries
    • Allowlist types if you must deserialize
    Reality

    Many “readObject” CVEs are preauth RCE. Treat untrusted deserialization as a critical finding in reviews.
